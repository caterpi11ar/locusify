# 小红书笔记创作与运营 Skill

小红书的本质是**生活方式搜索引擎 + 种草社区**：一半流量来自推荐信息流，
另一半来自站内搜索——这是它和抖音最大的不同，也是普通人做小红书的
最大机会：**内容有长尾**，一篇笔记可以被搜索持续带流量数月。

## 平台双引擎逻辑（一切方法的地基）

1. **推荐引擎**：新笔记先进小流量池，按互动率（点赞/收藏/评论/关注/
   停留）决定是否推入更大池子，逐级赛马
2. **搜索引擎**：用户搜"XX 怎么选""XX 攻略"，笔记靠**标题与正文的
   关键词覆盖**排序。搜索流量转化意图强，是种草变现的主力
3. 结论：**标题为搜索写，封面为推荐写**——标题埋用户会搜的词，
   封面抢信息流里的 0.5 秒注意力

## 笔记创作方法

### 标题（20 字内，必埋搜索词）

- 公式：**人群/场景 + 关键词 + 结果/情绪**。
  例："小个子|通勤穿搭|一周不重样"、"新手养猫|第一个月|避坑清单"
- 自查：把自己当用户，这个标题里有没有你会在搜索框里打的词？
- 不要标题党：小红书用户对"惊了""绝了"已免疫，具体数字和场景
  比感叹词有效

### 封面（信息流里的 0.5 秒）

- 三种可靠形态：**对比图**（前后/好坏）、**清单图**（大字列要点）、
  **场景实拍+大字标题**
- 图上文字 ≤ 12 字，手机缩略图下要能看清
- 首图决定点击，2-9 图承载内容——教程类把步骤拆进图里，
  用户为"收藏价值"点收藏

### 正文结构（种草文骨架）

```
钩子（前两行，折叠线之上）：痛点场景 or 结果前置
↓
个人经历锚点（为什么信我：真实使用/踩坑经历）
↓
干货主体（清单化，每点一行小标题+两三句展开）
↓
行动引导（收藏理由 / 评论区提问引导互动）
```

- **真实锚点是关键**：具体价格、具体时长、具体失败经历。
  通篇"绝绝子"没有细节的笔记，用户和算法都不买账
- 表情符号做视觉分段（每段开头一个），不要堆砌

### 标签

- 5-10 个：大词（穿搭）+ 精准词（小个子穿搭）+ 长尾词（158 小个子
  冬季通勤穿搭）三层覆盖，长尾词才是搜索排名的突破口

## 数据诊断（按漏斗定位问题环节）

| 症状 | 问题环节 | 对策 |
|------|----------|------|
| 曝光低（小眼睛少） | 没进流量池：标签/关键词覆盖差，或账号权重低 | 检查标题搜索词；排查是否触发限流（见合规） |
| 曝光高点击低 | 封面/标题不行 | 换封面形态重发验证 |
| 点击高互动低 | 正文没价值或钩子后露馅 | 加真实锚点、清单化重构 |
| 赞多收藏少 | 情绪共鸣有、留存价值无 | 往"可执行清单"方向改 |
| 收藏多不涨粉 | 单篇有用但账号无预期 | 做系列选题，主页统一定位 |

## 合规红线（限流/封号高发区）

- **站外引流是最高压线**：简介/评论/私信留微信号变体（V、薇、➕）
  都会被识别，轻则限流重则封号。要私域用平台允许的企业号工具
- **软广判定**：疑似接单推广但未通过官方"蒲公英"报备，会被限流。
  接商单走报备是唯一稳妥路径
- **违禁词**：医疗功效断言（祛痘/美白/治疗）、绝对化用语（第一/最）、
  P2P/加密货币类金融内容高危。发布前用平台自带的体检中心自查
- 搬运/洗稿会被原创保护机制打击，二创必须有实质增量

### 发布前自查工具（本 skill 附带）

`scripts/content_check.py`（零依赖，纯本地规则检测，不联网）：

```bash
python3 scripts/content_check.py 笔记文案.txt
echo "文案内容" | python3 scripts/content_check.py -
# ❌ 高危（绝对化用语/医疗断言/引流特征）→ 退出码 2
# ⚠️ 警告（正文过短/感叹号堆砌）→ 退出码 1
```

agent 替用户写完笔记后**必跑一遍**再交付；规则库覆盖常见红线
但非完备，平台最终判定以官方体检中心为准。

## Agent 典型用法

1. **写笔记**：给主题+人群 → 按上述骨架产出标题（含搜索词）+
   封面文案 + 正文 + 三层标签，并跑一遍合规自查
2. **诊断**：用户报笔记数据 → 按漏斗表定位环节，给一条可执行改法
3. **选题**：给定领域 → 生成"大词+长尾词"选题矩阵，优先做搜索
   竞争小、意图强的长尾题
4. **账号定位**：领域+人设+内容系列规划，保证主页"三秒看懂你是谁"

## 本 skill 不做什么

- 不提供爬取小红书数据、批量注册、刷量养号的方法（黑产高危）
- 算法权重细节属平台机密且随时调整，本文只保证"漏斗逻辑"层面
  长期有效，具体数值以官方创作者中心为准
- 商单报价因粉丝量/领域差异大，以蒲公英平台实时行情为准
