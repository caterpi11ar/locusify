## 入口与导航

保留 `/en/`、`/zh-CN/` 现有地图及回放功能，新增同语言 `/photos` 页面。地图工具区与照片页顶部都提供“地图 / 照片”切换，当前项明确标识；导入入口复用现有 PhotoSelector。照片数量来自共享 photoStore，不能只读 GPS markers。

照片页采用上游比例瀑布流与虚拟化布局：原始宽高经设备解码确定，不裁切成统一正方形，不伪造拍摄时间。按导入顺序稳定排列；未知拍摄日期显示“日期未知”。加载时保留比例占位，失败项保留在原位置，显示“无法读取此照片”和重试/移除按钮。

点击照片打开本地详情层；关闭、Escape 和浏览器返回恢复原瀑布流滚动位置并将焦点还给该照片。详情选中 ID 只保存在内存，不放入路径、查询参数或日志。详情中“在地图查看”仅对有效 GPS 可用，切至同语言地图并选中相同照片。无 GPS 项显示“无位置信息”，依然可查看详情。地图标记/聚合沿用上游交互，与照片页共用选中状态；标记打开相同本地详情。返回照片页恢复之前位置。删除当前照片时关闭详情并将焦点移至相邻项或导入入口。

## 状态与文案

| 状态 | 行为 |
| --- | --- |
| 空图库 | “添加照片，开始整理旅程”；提供本地导入按钮及“照片仅在此设备处理”说明 |
| 有照片但全部无 GPS | 瀑布流正常；地图提示“这些照片没有位置信息”，提供返回照片按钮，不调用定位 |
| 解码失败 | 单卡错误，不使整页崩溃；允许重试/移除，不上传诊断数据 |
| 地图/WebGL 失败 | “地图暂时无法显示”；重试及返回照片，不影响本地照片与详情 |
| 本地底图缺失/损坏 | “离线底图不可用”；照片仍可查看，禁止在线瓦片回退，重试只读取固定本地资源 |
| 刷新后会话为空 | 回到空图库，不恢复旧 blob URL 或不存在的照片 |

首版底图只使用来源及分发许可已核定的固定低精度数据。不按照片范围下载，不做在线逆地理编码，不增加定位按钮。已有同源 Natural Earth 数据可作为候选，但在核对来源、版本、许可前不宣称已批准。地图不依赖外部 glyph/sprite；若不使用文字或精灵图层，不发相关请求。worker 随构建本地打包。国家级底图明确标注“离线概览 · 不含街道细节”，不暗示街道精度。

## 组件与响应式

沿用 `index.css` 的 primary/background/foreground/border 颜色、现有字体及 Button/GlassButton/Dialog 组件。标准控件使用 `--ctl-height-md`（44px）、`--ctl-radius-md`（12px）、8px 控件间距。页面边距移动端 16px、桌面 24px；瀑布流间距 8px，保留上游按容器宽度计算列数的核心。窄屏至少一列、常规手机两列，桌面按约 240px 最小列宽自适应，不横向溢出。

手机顶部切换与导入按钮保持可达；详情使用全屏 Dialog，桌面使用居中大图层。关闭按钮不被刘海/安全区遮挡。键盘可操作全部卡片和控制项，Dialog 限制焦点、关闭后恢复焦点；减少动态效果偏好下关闭非必要动画。地图控制与底部署名不重叠，不遮挡照片卡片。

## 与上游的明确差异

1. 公开 manifest 改为本地 File/blob，尺寸来自真实解码；不附带云媒体转换与社交功能。
2. 站点路由和 query 选中 ID 改为 Locusify 语言路由与内存选择，详情返回恢复滚动/焦点。
3. 保留既有回放/导出，新增可达照片页，不整体覆盖地图目录。
4. CARTO 在线底图改为固定本地低精度资源，移除定位和远程样式配置入口。
5. UI 使用 Locusify 组件/token；元数据图标使用现有图标库，逐项记为适配。
6. 不引入上游遥测/远程字体；现有 GA 与 SpeedInsights 也不得挂载于可接触本地照片状态的应用运行环境。
7. 增加无 GPS、空、失败、离线资源缺失和可见许可状态。
